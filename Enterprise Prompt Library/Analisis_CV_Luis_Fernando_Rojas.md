# Clasificación de Curriculum Vitae

## Clasificación
**Categoría:** Semi Senior
**Subcategoría:** Desarrollador de Software / Backend (.NET)
**Nivel de confianza:** Medio

## Justificación
El candidato acumula aproximadamente 5 a 7 años de experiencia laboral continua en el área de desarrollo de software (2019 – Presente), lo cual supera el rango habitual de un perfil Junior. Sin embargo, no cumple con los criterios para ser considerado Senior debido a la total ausencia de evidencias vinculadas a liderazgo técnico, arquitectura de sistemas, gestión de equipos o tutoría de desarrolladores. Su trayectoria demuestra una progresión operativa desde roles de soporte e incidencias hacia el mantenimiento y desarrollo de funcionalidades web.

## Evidencias encontradas
- **Experiencia:** 
  - Programador Junior en Empresa de Servicios (2019 – 2021).
  - Desarrollador de Software en Empresa de Tecnología (2021 – Actualidad).
- **Tecnologías:** C#, .NET, SQL Server, HTML, CSS, JavaScript.
- **Liderazgo:** No se registran evidencias de liderazgo de proyectos, coordinación de equipos, decisiones de arquitectura ni mentoría.

## Observaciones
La información proporcionada presenta un nivel de detalle limitado respecto al impacto de los proyectos, las versiones específicas del stack tecnológico (ej. .NET Core, .NET Framework, SQL Server versions) y el uso de metodologías agiles o herramientas DevOps. Por esta razón, el nivel de confianza se mantiene en un rango Medio.
